adsb2dd operator

Health, configs, runtime.

Minimal control surface for saved configs, live output, and explicit API inspection.

Health

Loading

Use this to confirm the service is alive. If Errors flips to Yes, check the status panel and the selected config runtime for the failing source or stale run.

Example commands

curl -sS http://localhost:3000/api/health
curl -sS http://localhost:3000/api/status

Status

Raw service summary. This is the quickest place to verify active configs, last process time, aircraft counts, and whether Doppler is warming or ready. 


        


        

          

            
Saved Configs

            
          

          

            Save known RX/TX/server combinations here. Start pins a config so it stays active without
            query-string polling. Inspect loads runtime and output in the panel below.
          

          

        


        

          

            
Create Config

          

          

            Enter positions in meters and the tar1090 base URL, for example http://host/tar1090. This
            stores the config on disk so it can be started later from the UI or API.
          

          

            
            
            

              
              
              
            

            

              
              
              
            

            
            
            
            

              
              
            

          

          

          

            
Example command

            
curl -sS -X POST http://localhost:3000/api/configs \
  -H 'Content-Type: application/json' \
  --data '{"name":"Leesburg DC101","server_url":"http://100.65.214.53/tar1090","rx":{"latitude":39.0792,"longitude":-77.55252,"altitude":50},"tx":{"latitude":38.999833,"longitude":-77.0572,"altitude":750},"fc_mhz":101.1}'

          

        


        

          

            
Runtime / Output

          

          

            Runtime shows whether the selected config is idle, warming, running, or failing. Output shows current
            aircraft results. Delay should appear first; Doppler appears only after enough valid samples accumulate.
          

          
Select a saved config.

          

            
          

          

          

          

            
Example commands

            
curl -sS http://localhost:3000/api/configs/<id>/runtime
curl -sS http://localhost:3000/api/configs/<id>/output
curl -sS -X POST http://localhost:3000/api/configs/<id>/start
curl -sS -X POST http://localhost:3000/api/configs/<id>/stop

          

        


        

          

            
Manual API Inspector

            Explicit use only
          

          

            Use this when you want to see a specific request and response without dropping to a shell. It does not
            record traffic automatically; it only sends what you ask it to send.
